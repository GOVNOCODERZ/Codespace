Лабораторная работа №3: Параллельные алгоритмы сортировки в OpenMP и их практическое применение
================================================================================================

Состав исходного кода:
- common_stats.h    — расчёт доверительного интервала (AvgTrustedIntervalAVG, bubbleSort, AvgTrustedIntervalMed)
- BMPFileRW.h       — модуль чтения/записи 24-битных BMP-файлов (на базе методического модуля каф. ИВТ СибГУ)
- task3_1_sort.cpp  — Задание 3.1: последовательные и параллельные алгоритмы сортировки (пузырёк, чёт-нечётная, Шелла, qsort)
- task3_2_median.cpp — Задание 3.2: последовательная и параллельная медианная фильтрация 24-бит BMP (Шелла и qsort)
- Makefile          — сценарий сборки для GCC / MinGW-w64 (UCRT64)

Команды компиляции (GCC/Clang, без ошибок и предупреждений -Wall -Wextra):
  g++ -std=c++17 -fopenmp -O3 -march=native -Wall -Wextra task3_1_sort.cpp -o task3_1.exe
  g++ -std=c++17 -fopenmp -O3 -march=native -Wall -Wextra task3_2_median.cpp -o task3_2.exe

Запуск:
  ./task3_1.exe          (полная серия замеров: 30/35/110 запусков, int и double, 20000/35000/50000)
  ./task3_1.exe --demo   (быстрая демонстрация работы в консоли)
  ./task3_2.exe          (полная серия замеров по input_1..4.bmp, Ksize = 7, 11, 15, >=15 запусков)
  ./task3_2.exe --demo   (быстрая демонстрация работы в консоли)
